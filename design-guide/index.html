01 · Principles

Quiet confidence, built from useful detail.

The system prioritizes legible content, real installation proof, and direct paths to action. Restraint is a functional choice: each visual device must clarify hierarchy, relationship, or state.

Lead with the outcome

Explain what becomes simpler or more reliable before describing equipment. Keep one dominant message and one primary action per viewport section.

Let structure do the work

Use type, spacing, grid alignment, and solid fields before adding containers, shadows, or decorative color.

Show credible proof

Prefer authentic Blyx installation photography with clear device and architectural context. Captions identify useful specifics.

Design every state

Hover, focus, active, loading, disabled, success, and error states are part of the component—not implementation afterthoughts.

02 · Typography

One typeface, a deliberate hierarchy.

  • Limit uppercase labels to four words.
  • Do not add manual line breaks by default.
  • Use underlines for links inside body copy.
  • Never reduce body or form text below 16px.

07 · Imagery

Installation detail is the evidence.

Use authentic project photography first. Keep the subject, its architectural anchor, and enough context to understand the work. Text never sits over detailed photography.

Hard crop

Default treatment

Use: the default for proof, gallery, and detail images. Crop tightly enough to identify the work, never through the focal device or a proof-bearing detail.

Selection checklist

  • The focal device or finish is immediately identifiable.
  • One construction edge or material change gives context.
  • The crop removes unrelated room or lifestyle detail.
  • Intrinsic dimensions and responsive sources are present.
  • Alternative text states useful visual information.
  • Soft or undersized assets are flagged before production; upscaling requires explicit approval.

Avoid generic lifestyle stock, fake interface overlays, dramatic color grading, text over photography, ornamental gradients, and fades that cross the focal subject.

Copy-facing seam fade

Light + inverse fields
Surface
Inverse surface

Use: bind the fade to the field beneath the image. Below 48rem—or without mask support—the complete hard crop remains.

Responsive implementation

  • Use media-specific <source> elements when compact and wide compositions require different crops.
  • Use width descriptors and an accurate sizes value when only resolution changes.
  • Keep intrinsic width and height on the fallback image to reserve layout space.
  • Set compact and wide focal positions per asset; do not accept centered cropping by default.
  • Keep captions and controls outside every mask and overlay stacking context.
08 · Page review

A repeatable check before release.

Review a page in this order. Correct structure and clarity before polishing local detail.

Page-level checks

  1. One clear page promise, one semantic h1, logical heading order.
  2. Every value maps to a shared token or documented exception.
  3. Text measures, grid spans, and section rhythm match their roles.
  4. Every action and form state is understandable without color alone.
  5. Imagery proves the work, protects the focal subject, and uses only approved enhancements.

Responsive and access checks

  1. Inspect at 320, 768, 1024, 1280, and 1440 CSS pixels.
  2. Test keyboard order, focus visibility, and menu behavior.
  3. Test 200% text zoom and browser font-size preferences.
  4. Confirm solid-field contrast for every state.
  5. Block the web font and images; content must remain usable.
